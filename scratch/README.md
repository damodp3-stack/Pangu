# 🧪 Scratch & Experimental Testing Suite

This folder contains offline test runners, experimental model rig generation scripts, and visual frame verification tools used during development of Pangu's 3D models (such as `SellswordFox`, procedural textures, and WebGL animation pipelines).

### Highlights:
- **`build_sellsword_fox.js`**: Generates and inspects the warrior fox anatomical rig.
- **`run_capture.js` & `render_script.js`**: Offline rendering verification.
- **`test_pangu_ui.js` & `verify_full_system.js`**: Headless regression test scripts.

*Note: These files are development scratch utilities and are ignored by production builds.*
