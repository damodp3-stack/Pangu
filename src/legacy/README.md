# 📜 Legacy 2D Engine Archive

This directory preserves the original **2D HTML5 Canvas Sprite Engine** (`pangu_character.js`) created during early prototyping of Pangu before transitioning to the full native **3D Three.js Quadruped Rig Engine** (`src/ui/components/pangu_3d.js`).

### Purpose:
- Historical reference for 2D sprite particle math and character physics algorithms.
- Kept isolated from active runtime bundles to ensure zero bloat in production.
